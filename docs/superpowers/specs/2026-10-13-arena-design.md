# 峡谷之战设计

独立浏览器 MOBA 原型，原创绘制素材。三路地图、蓝红阵营各五名英雄、自动兵线、防御塔、水晶、两处野怪。玩家控制剑士，AI 英雄参与推进与战斗。击杀带来金币、经验；商店强化属性，升级提升战力。支持死亡复活、回城、恢复、闪现、三个技能、暂停、重新开始。

Canvas 等距战场，HTML 大厅、HUD、技能栏、商店、设置与结算。无外部素材依赖，静态文件可部署 CDN。键鼠与触屏两套输入。核心模拟独立模块可在 Node 测试。

验证覆盖兵线生成、伤害、冷却、经济购买、死亡复活、水晶胜负与完整长时间模拟。浏览器验证页面加载、开局与操作。发布需可用 CDN 上传目标；没有账号入口时交付静态部署包并明确状态。
