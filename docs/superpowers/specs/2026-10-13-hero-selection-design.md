# 英雄选择与人物升级

大厅进入独立英雄选择页，默认五位英雄：李白、铠、貂蝉、孙尚香、孙悟空。使用公开官方展示原画与头像，保留来源说明。选中后展示职业、属性、技能与故事，确认后将所选英雄的身份、战斗属性、技能与外观传递给实际对局。返回大厅与重新选将都保持可用。

角色采用本地 Three.js 构建的三维形象，具有自然身材比例、分层服饰、脸部、发型、手指、金属武器。选择页可切换原画和可旋转三维预览；战场使用同一模型渲染的多方向动画帧，兼容现有 Canvas 世界。3D 初始化失败仍可选将并对战，选择页回退原画。静态资源全部本地托管，避免运行依赖第三方服务。

核心测试覆盖英雄配置、技能差异、非法选择回退与原有对局。浏览器覆盖五位角色切换、确认选将、HUD、攻击技能、3D 预览与移动端布局。完成后更新原 GitHub Pages。
