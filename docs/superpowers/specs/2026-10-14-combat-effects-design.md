# 英雄技能与战斗特效

为五位英雄重建普攻、弹道、连续技能、被动触发与专属特效。采用可计时的弹道与技能事件驱动伤害；渲染只读取状态，避免视觉与实际命中不同步。

李白：两次突进与返回原点、剑圈、四次普攻解锁大招、五连剑影。铠：弹跳后返回的刀刃、两次挥斩与强化普攻、八秒魔铠。貂蝉：往返花球、三枚追踪花瓣、四层花印爆炸、加速冷却的持续莲花法阵。孙尚香：翻滚后强化射程与普攻、延迟落地爆弹、飞行重炮。孙悟空：成功抵挡触发护盾、跃进强化下一棒、大招震地与标记强化。

Canvas 专用特效层绘制弧形剑光、残影、拖尾、发光粒子、炮口焰、爆炸、莲花纹样、魔铠、金箍棒与地裂。特效数量和粒子数设上限；移动端降低粒子密度。玩家与 AI 共用技能与普攻逻辑。HUD 显示多段技能、强化普攻和李白大招解锁状态。

这是对招牌机制与视觉风格的独立重现，数值为浏览器原型的平衡参数，不声称与商业游戏所有版本完全一致。

验证：各英雄技能阶段、飞行时间、往返命中、强化普攻消耗、法阵范围与冷却、护盾、事件清理；浏览器逐英雄截取战斗画面、验证手机技能与无 WebGL；更新既有 GitHub Pages 并检查公网资源。
