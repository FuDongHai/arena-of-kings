# 峡谷之战 · Arena of Kings

非官方浏览器 MOBA 玩法演示。包含李白、铠、貂蝉、孙尚香、孙悟空的英雄选择页、原画与 3D 旋转预览。

战场形象采用 Three.js 独立重建，具有专属服饰与武器、八方向与行走／攻击姿态；不是官方游戏模型。动作帧已预先导出，战斗不要求 WebGL，3D 预览支持时按需创建角色。五位英雄拥有独立战斗属性、弹道与连段技能，叠加剑影、花瓣、魔铠蓝焰、重炮和金箍棒裂地特效。技能参照角色标志性机制独立实现，数值和细节是浏览器原型的简化版本。

运行：`npm start`，访问 http://127.0.0.1:4173 。测试：`npm test`。

玩法：5v5 人机战斗、三路兵线、防御塔、水晶、野怪、装备、升级、死亡复活。摧毁敌方水晶获胜。

WASD / 方向键移动，右键指定目的地，鼠标指向技能方向，J / 空格 / 左键普攻，Q / E / R 三项英雄技能，C 恢复、Shift 闪现、F 回城、B 商店、Esc 暂停。手机横屏游玩，左侧摇杆移动，右侧按钮施法。进入对局会尝试全屏与横屏锁定；Safari 等不支持锁定的浏览器请手动旋转并关闭系统竖屏锁定。手机竖屏时显示旋转提示并暂停模拟，恢复横屏后继续，保留用户手动暂停状态。手机技能方向跟随摇杆方向。

## GitHub Pages

将整个项目上传仓库，保留 assets/、vendor/ 与根目录所有 HTML、CSS、JS 文件。仓库 Settings → Pages → Deploy from a branch → main / root。没有构建步骤；运行时资源均本地托管。

这是单机 Canvas 原型，不包括真人联网、商业游戏级角色模型、账号与匹配系统。

## 浏览器检查

安装 Playwright 后，启动 npm start，再运行 node tests/hero-browser-check.cjs。可通过 CHROME_PATH 指定已安装 Chrome，通过 GAME_URL 指定公网版本。测试覆盖五位选将、筛选、3D、HUD、技能、重新选将与手机布局。

## 专属技能

- 李白：将进酒两段突进、第三段返回；剑阵边缘伤害；四次普攻解锁五段青莲剑歌。
- 铠：弹射回旋刃返回回血、双重挥砍与强化普攻、8 秒魔铠。
- 貂蝉：往返花球、位移追踪花瓣、四层花印爆炸；莲阵加快技能冷却。
- 孙尚香：翻滚强化下一次穿透普攻、延迟爆弹、飞行重炮爆炸。
- 孙悟空：成功挡招后护盾、腾云强化棒击、震地眩晕和三层棒击印记。

伤害由模拟弹道与定时事件结算；AI 也使用相同技能。特效粒子按屏幕尺寸减量，使用有界弹道拖尾。`node tests/combat-browser-check.cjs` 检查五位英雄和移动端特效，可使用上述浏览器环境变量。

人物模型资源的外观核对、许可、下载限制及接入方式见 [MODEL_RESOURCES.md](MODEL_RESOURCES.md)。

卡死回归检查：`node tests/movement-browser-check.cjs`，覆盖无专属颜色的小兵交战、李白持续移动及普攻／技能、桌面和手机尺寸，支持同样的 GAME_URL / CHROME_PATH / PLAYWRIGHT_MODULE 环境变量。

普攻拥有七帧抬手、挥击与收势，命中在前摇结束后结算；眩晕或施法会打断前摇。开局三路兵线立即出发，每 18 秒增援，每路两名近战兵、一名远程兵，开局及每第三波加入炮车。`node tests/landscape-browser-check.cjs` 检查手机触摸布局、竖屏暂停／横屏恢复、手动暂停保持、兵线和普攻命中。
